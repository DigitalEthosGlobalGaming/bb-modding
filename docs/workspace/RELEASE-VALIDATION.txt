Boundaries
  Bloodborne was not launched and no computer-use automation was used for this
  release. Gameplay and visual acceptance remain for the user. Read TEST-WHEN-BACK.
  The new UI is the host overlay. Native System-menu creation/modification and
  interception are researched, not implemented. See equipment-ui-research.md.
  Equipment hand/armor labels remain unconfirmed. Exact matches can resolve item
  IDs without guessing labels. Inventory is carried items, not storage.
  Native attack records identify behavior/source, not a weapon, hit or damage.
  Coverage is conditional and multiple records can represent one action.
  Sampled HP changes are not native damage events. Scaling claims affect explicit
  SDK adjustments only, not natural damage or regeneration. Test defaults observe.
  Event queues are bounded; contention/overflow can drop records with diagnostics.
  Each native observer retains one bounded trampoline allocation until process
  exit for cached calls; it cannot reinstall repeatedly in the same process.
